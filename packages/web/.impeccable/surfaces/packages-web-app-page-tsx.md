## Register

**brand** — for this surface only.

`PRODUCT.md` declares `register: product`. That is correct and governs the session UI,
where someone completes a task. It does **not** govern this route. Register is selected
from the surface, not the product: the landing page is where someone decides, and there
design is the product. Anything applying `register: product` to `app/page.tsx` is reading
the wrong scope.

Mode: **Persuade**.

## Job and audience

Two to six engineers who already use an AI coding agent individually and want to do it
together. They arrive from a shared link or a demo. The page has to answer, in one
viewport, what Relay is and why watching an agent together needs a product at all.

Primary action is a command (`npx relayrun`), never a button. Sessions are created by the
CLI on the host's own machine — the page has no repository, so there is no "start" it
could honestly offer.

## Visual authority

The Nexflow Framer template (<https://nexflow.framer.media/>), matched deliberately and
by measurement rather than by impression. Values live in `LANDING_REFERENCE_MATCH.md`;
the short version:

- Geist 400 for display, Geist Mono for all chrome. Presence comes from size and −0.05em
  tracking, never from weight.
- `#0A0A0A` ground — not pure black. Alpha hairlines, 1200px measure, zero radius.
- **Chrome is achromatic.** The reference's own chrome measures 4 chromatic fills out of
  156; its colour lives inside product screenshots, not its interface.
- Status colour therefore belongs only to product surfaces — the ledger, badges, control
  bar — sampled from the reference's own imagery.

## Boundaries

- No customer logos, testimonials, pricing or waitlist. Relay has none of those, and
  invented social proof is the one thing on a portfolio page that cannot survive a
  follow-up question.
- No stock photography. The dithered band is generated by `scripts/generate-dither.py`.
- The session UI is a different register. Token changes reach it; layout decisions taken
  here do not.
- Dark only, no toggle.
- Contrast is measured by canvas pixel readback with alpha compositing, never estimated —
  reading a semi-transparent fill straight off `getImageData` returns it unpremultiplied
  and silently reports a passing ratio for a tinted row.
